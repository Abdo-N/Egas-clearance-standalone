Purpose and authority

An Admin manages operational user accounts. Admins do not process or view employee clearance requests and cannot manage Admin or Super Admin accounts.

Your boundary: you may manage only file_management and reviewer accounts. Ask the Super Admin to manage an Admin account.

1. Sign in and password security

Login screen. The demo-account picker is a development feature and may be absent in production.

  1. Open the website address supplied by IT.
  2. Enter your work email and password. There is no self-registration.
  3. Select Log in; the system routes you to the Admin dashboard.
  4. Use the language/theme controls as needed and log out when finished.

Temporary password

If the Super Admin reset your password, the temporary password only permits you to open Set new password. Choose at least 12 characters containing a symbol. There is no skip option.

Re-authentication

Creating, resetting, and deleting accounts requires your current password again. Enter your own password—not the affected user’s.

Forgotten password

Use the help link on the login page to obtain Super Admin contact details. Password recovery is assisted; the system does not email reset links.

2. Create operational accounts

Admin dashboard: account creation form and accounts within the Admin’s management boundary.

  1. Enter your current Admin password in the confirmation field.
  2. Enter the employee’s full name, internal landline number, work email, and a strong temporary password.
  3. Choose Document and Records Management or Department Reviewer.
  4. For a reviewer, select the correct department. For IT, also select one unclaimed checklist item.
  5. Review every value, create the account, and transmit the temporary credential through an approved secure channel.
  6. Tell the user that the site forces a permanent password at first login.
IT assignment is exclusive: each of the five IT checklist items can belong to only one account. If an item is unavailable, verify the existing account instead of assigning a different item as a workaround.

3. Reset or delete accounts

Reset a forgotten password

  1. Confirm the user’s identity according to EGAS policy and match the exact email.
  2. Select Reset password, enter your own password, and set a strong temporary password.
  3. Send it securely. The user must replace it immediately after login.

Delete an account

  1. Confirm the exact email, employment status, replacement coverage, and organizational approval.
  2. Select Delete, read the warning, and enter your current Admin password.
  3. Confirm deletion only when permanent removal is intended.
Deletion is permanent. Do not delete an account merely to resolve a password problem. Before deleting a reviewer—especially an IT owner—ensure another appropriately assigned account can cover future work.

Before ending a session

  • Verify created accounts have the correct email, role, department, and IT assignment.
  • Do not record temporary or Admin passwords in tickets or screenshots.
  • Confirm operational coverage before deleting an account.
  • Log out on shared workstations.
  • Escalate unexpected permissions or data visibility to IT immediately.
